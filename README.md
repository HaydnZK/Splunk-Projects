# Splunk Projects
Welcome to my Splunk Projects repository. This repo contains multiple hands-on Splunk investigations, detection labs, and SIEM exercises that show how Splunk can be used to detect and analyze suspicious activity on Linux systems and beyond.

Each project is in its own folder with detailed notes, screenshots, and Splunk search queries that walk through the investigation step by step. These projects show both technical execution and the reasoning behind the investigation.

---

## Projects
### Data Exfiltration Detection
Path: `Data-Exfiltration-Detection`

This project is a full attack investigation using Splunk. It starts with an internal credential compromise and ends with data exfiltration and persistent access. It includes:

- How the attack was simulated and logs were generated  
- Splunk configuration for Linux logs  
- Step-by-step investigation with Splunk search queries  
- Screenshots showing the timeline of the attack  
- Detection of persistence mechanisms  
- Notes that can be used for presentations or teaching

**View project →** [Data-Exfiltration-Detection](./Data-Exfiltration-Detection)

## How to Use These Projects
Each project folder contains:

- A detailed `README.md` with the investigation notes  
- Screenshots that match each search step  
- Splunk search queries you can run  
- Optional folders for searches, diagrams, and other artifacts

Start by reading the notes, then match the screenshots with the searches to see how the investigation unfolds in real time.
